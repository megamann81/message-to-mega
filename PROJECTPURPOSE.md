## *Message to Mega Project Purpose*
>This markdown file was made to explain this projects purpose for the Stardance Challenge project

  Message to Mega was created as a means for people to send messages to me without any judgment and to claim a spot in the registry, like historic visitor websites people have made in the past. People on the website can post a message of their own, use their own username, see other people's messages, and give suggestions on the website. The website features responsive mobile styling that adapts to mobile browsers. The backend for the project is located at
```text
https://wcafxaensepvnhzebixg.supabase.co
```
The backend is not publicly editable, so if someone would like me to delete one of their messages they are encouraged to contact me at luke.ib.bronson@gmail.com.
Generally, message submissions are run through the backend to allow them to speak their mind, but prevent any kind of blocked words or phrases, spam, promotion, urls, etc. (full list can be found in  [the project README](README.md)) I have also added an adjustable backend variable to change the message character limits easily preventing extremely long messages. Some other features that I have added are a side bar with a page index that allows you to quickly jump to a section and a contact section, a spotify widget that updates to a playlist I have made, a clickable heart counter on the side, and suggestion form box for playlist suggestions. I am currently working on improving the form and am considering removing the spotify widget to protect my personal account privacy. I may also add a total visitor count and remove some of the unnecessary animations in order to be more resource efficient. This project is currently licensed under an [MIT license](LICENSE.md).
